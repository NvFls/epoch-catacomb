### 一、分压法

**鹅大爷的理解**：
“分压法，就是让电压自己分家。把两个电阻串在一起，电压就分成两股，一股去大的，一股去小的。我只要量一量它们身上的电压，再一除，就能知道谁大谁小。这就像分蛋糕，谁吃得多谁块大。”

**电路图**：

```
    ┌───[R₁]───┬───[Rₓ]───┐
    │            │           │
   [电源]      [V₁]       [V₂]
    │            │           │
    └────────────┴───────────┘
```

**说明**：
- \(R_1\) 是已知阻值的标准电阻
- \(R_x\) 是待测的超导体
- \(V_1\) 和 \(V_2\) 是两个电压表，分别测量 \(R_1\) 和 \(R_x\) 两端的电压
- 根据分压公式，\(R_x = R_1 \times \frac{V_2}{V_1}\)

**实验现象**：
鹅大爷接好电路，发现两个电压表读数几乎一样（因为超导体电阻极小）。他挠挠头：“这电压怎么没分家？两个表一样，那不就是 \(R_x = R_1\)？不对啊，超导体应该比 \(R_1\) 小很多……”

他最终得出结论：“分压法不适合测超导体，因为电压不会分给短路的家伙。”

### 二、限流法安安法

**鹅大爷的理解**：
“限流法，就是让电流过不去，逼它绕路。我在电路里串一个限流电阻，再串一个电流表，电流就乖乖地从表里走。然后我再并联一个电压表，读个数，一算就知道电阻。这叫‘安安法’，因为电流表叫‘安培表’，我要安安静静地看它走。”

**电路图**：

```
    ┌───[R限]───┬───[A]───┐
    │            │          │
   [电源]      [Rₓ]        │
    │            │          │
    └────────────┴───[V]───┘
```

**说明**：
- \(R_{\text{限}}\) 是限流电阻，防止电流过大
- \(A\) 是电流表，测量总电流
- \(V\) 是电压表，并联在待测电阻 \(R_x\) 两端
- 根据欧姆定律，\(R_x = \frac{V}{I}\)

**实验现象**：
鹅大爷接好电路，发现电流表读数很大，电压表读数几乎为零。他挠头：“电压没有，电流很大，这电阻就是零啊！不对，那限流电阻干嘛用的？烧了？”

**鹅大爷的理解**：

**电路图**（惠斯通电桥）：

**说明**：
- 调节已知电阻 \(R_1, R_2, R_3\)，使检流计 \(G\) 读数为零（电桥平衡）

## 电阻箱等效法（惠斯通电桥法）测量电阻

---

### 一、测量原理

电阻箱等效法基于**惠斯通电桥原理**。其核心思想是通过调节已知电阻的比值，使桥路达到平衡（检流计指零），从而根据比例关系计算出待测电阻的阻值。

**原理图**：

```
        ┌───[R₁]───┬───[Rₓ]───┐
        │           │           │
       [电源]      [G] 检流计  │
        │           │           │
        └───[R₂]───┴───[R₃]───┘
```

**平衡条件**：
当检流计G读数为零时，B、D两点电位相等，此时有：
\[
\frac{R_1}{R_2} = \frac{R_x}{R_3}
\]

从而：
\[
R_x = R_1 \times \frac{R_3}{R_2}
\]

其中 \(R_1\)、\(R_2\)、\(R_3\) 均为已知阻值的精密电阻箱。

---

### 二、测量设备

| 设备名称 | 规格要求 | 数量 | 备注 |
|---------|---------|------|------|
| 直流稳压电源 | 3-6V，稳定可调 | 1台 | 电压不宜过高 |
| 检流计 | 灵敏度不低于10⁻⁶A/格 | 1台 | 可用光点检流计 |
| 电阻箱A | 0-9999.9Ω，精度0.1% | 1个 | 用于 \(R_1\) |
| 电阻箱B | 0-9999.9Ω，精度0.1% | 1个 | 用于 \(R_2\) |
| 电阻箱C | 0-9999.9Ω，精度0.1% | 1个 | 用于 \(R_3\) |
| 待测电阻 \(R_x\) | — | 1个 | 待测量 |
| 连接导线 | 低阻铜线 | 若干 | 接头处需可靠 |
| 开关 | 单刀单掷 | 1个 | 控制电路通断 |

---

### 三、测量步骤

**步骤1：初始设置**
- 将电阻箱 \(R_1\)、\(R_2\)、\(R_3\) 调至适当值（建议先取 \(R_1 = R_2\)，\(R_3\) 调至与 \(R_x\) 预估阻值相近）
- 按原理图连接电路，确保所有接头牢固
- 检流计调零，电源电压调至3V

**步骤2：粗调平衡**
- 闭合开关，观察检流计偏转方向
- 调节 \(R_3\)，使检流计偏转逐渐减小
- 当检流计基本归零时，进入细调阶段

**步骤3：细调平衡**
- 交替微调 \(R_1\) 和 \(R_3\)（或固定 \(R_1\)、\(R_2\) 比值，只调 \(R_3\)）
- 每次调节后观察检流计，直至指零
- 记录此时 \(R_1\)、\(R_2\)、\(R_3\) 的阻值

**步骤4：计算 \(R_x\)**
\[
R_x = R_1 \times \frac{R_3}{R_2}
\]

**步骤5：重复测量**
- 改变 \(R_1\)、\(R_2\) 的比值（如取 \(R_1:R_2 = 1:10\)、\(10:1\) 等），重复步骤2-4
- 取多次测量结果的平均值作为最终测量值

---

### 四、注意事项

**1. 接触电阻问题**

由于待测电阻 \(R_x\) 可能很小（尤其当测量超导体时），连接导线的接触电阻不能忽略。建议：
- 使用粗短铜线
- 接头处压紧或焊接
- 可采用四端法接线（额外引出电压测量端）

**2. 检流计保护**

电桥严重不平衡时，检流计可能过载。建议：
- 初始调节时，在检流计回路中串联一个高阻保护电阻
- 接近平衡时再短接保护电阻提高灵敏度

**3. 电源稳定性**

电压波动不影响电桥平衡（平衡只与电阻比值有关），但电压过低会降低灵敏度。建议使用稳定直流电源。

**4. 超导体测量的特殊情况**

当 \(R_x\) 极小（趋近于零）时，平衡条件要求 \(R_1 \times R_3 \approx 0\)，这需要 \(R_1\) 或 \(R_3\) 中的一个也趋近于零。此时：
- 可以将 \(R_1\) 直接短路，调节 \(R_3\) 使电桥平衡
- 此时 \(R_x = 0\)（由短路 \(R_1\) 直接得出）

但需要注意的是，短路 \(R_1\) 会使电路变为简单的电阻分压，失去电桥的精度优势。对于真正的零电阻样品，最直接的证据是**短路法**：将超导体直接短路检流计两端，若检流计无偏转，说明其两端无电压降，从而证明电阻为零。

---

### 五、误差分析

| 误差来源 | 影响程度 | 消除方法 |
|---------|---------|---------|
| 电阻箱精度 | 主要误差 | 选用高精度电阻箱 |
| 检流计灵敏度 | 影响平衡判断 | 使用高灵敏度检流计 |
| 接触电阻 | 对小电阻影响大 | 四端法接线 |
| 热电势 | 微弱影响 | 切换电源极性取平均 |
| 环境温度 | 影响电阻值 | 恒温环境或温度修正 |

---

本方法符合 **南极共和国国家标准 GBZ 1003-2087《直流电阻测量通用技术规范》** 中的“电桥法”测量规程。对于精度要求高于0.01%的测量，建议改用 **双电桥（开尔文电桥）法**。

## 单电阻箱等效替代法测电阻

---

### 一、测量原理

单电阻箱等效替代法的核心思想是：**用电阻箱的阻值去“替代”未知电阻，使电路的工作状态完全相同**。这样，电阻箱显示的阻值就等于未知电阻的阻值。

这种方法只需要一个电阻箱，一个电流表（或电压表），和一个单刀双掷开关。

---

### 二、电路图

```
           ┌───[A]───┐
           │          │
          [电源]      │
           │          │
           └───[K]───┴───┐
                │          │
                ├──[Rₓ]───┤
                │          │
                └──[R]────┘
```

**图注**：
- \(R_x\)：待测电阻
- \(R\)：电阻箱（可调）
- \(A\)：电流表（也可用电压表，接法不同）
- \(K\)：单刀双掷开关，可在 \(R_x\) 和 \(R\) 之间切换
- 电源：直流电源（电池或稳压源）

---

### 三、测量步骤

#### 方法一：电流等效法（串联）

**连接方式**：
1. 按图连接电路，电流表串联在主电路中
2. 开关 \(K\) 先掷向 \(R_x\) 一侧

**操作步骤**：
1. 闭合电路总开关，记录电流表读数 \(I_1\)
2. 断开电源，将开关 \(K\) 掷向电阻箱 \(R\) 一侧
3. 重新闭合电源，调节电阻箱的阻值，使电流表读数回到 \(I_1\)
4. 此时电阻箱显示的阻值即为 \(R_x\) 的阻值

**公式**：
当两次电流相等时：
\[
\frac{U}{R_x + r} = \frac{U}{R + r}
\]
（\(r\) 为电源内阻和线路电阻之和）
两边相等可得：
\[
R_x = R
\]

---

#### 方法二：电压等效法（并联）

如果使用电压表，可改为并联接法：

```
           ┌───[Rₓ]───┐
           │          │
          [电源]      │
           │          │
           └───[R]────┘
               │
               └──[V]───
```

**操作步骤**：
1. 将电压表并联在 \(R_x\) 两端，记录电压 \(U_1\)
2. 将电压表改并联到电阻箱 \(R\) 两端
3. 调节电阻箱阻值，使电压表读数回到 \(U_1\)
4. 此时 \(R = R_x\)

---

### 四、注意事项

1. **电源稳定性**：整个过程中电源电压不能变化，否则两次读数没有可比性
2. **电流表精度**：为了提高测量精度，应选用灵敏度合适的电流表
3. **开关操作**：切换开关时应先断开电源，防止电流冲击损伤电表
4. **接触电阻**：接线处要牢固，尤其在小电阻测量时接触电阻会影响精度
5. **测量范围**：电阻箱的调节范围应覆盖待测电阻的预估阻值

---

### 五、优缺点

**优点**：
- 只需一个电阻箱，设备简单
- 操作直观，容易理解
- 消除了电源内阻、导线电阻的影响（因为两次测量条件相同）
- 精度取决于电阻箱的精度和电表的灵敏度

**缺点**：
- 需要手动切换和调节，效率较低
- 电源电压需保持恒定，否则会有误差
- 不适合测变化中的电阻（如热敏电阻）

---
