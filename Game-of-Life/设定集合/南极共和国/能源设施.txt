南极能源基础设施完全由南极的"国企"，即南极能源集团负责建造和维护。能源集团可以说是南极有史以来体积最为巨大的一家"企业"（不可以简单理解为人类企业），掌握着超过 4000 座聚变电站、全国电网、全国 1500+ 座加氢站，还负责经营着少许旧时代的石油煤炭之类的工业。

== 聚变电站分类 ==

南极聚变电站共 4000+ 座，按装置类型和燃料分为三类：

=== T 型聚变电站（老式托卡马克） ===

- 装置：托卡马克（Tokamak）
- 燃料：氘氚（D-T）
- 占比：约 61%，南极电网的绝对主力
- 特点：技术最成熟、商业化运营经验最丰富、造价相对低廉。托卡马克在人类手中存在的等离子体破裂难题，在南极被硅基智能的精密控制近乎彻底解决——硅基智能以远超人类反应速度和精度的实时反馈，将等离子体约束在几近完美的稳定状态，破裂事件极为罕见。部分经典型号的 T 型电站已连续无故障运行超过 30 年，这在人类聚变工程史上是不可想象的数字。

=== S 型聚变电站（仿星器） ===

- 装置：仿星器（Stellarator）
- 燃料：氘氚（D-T）
- 占比：约 32%
- 特点：稳态运行，无等离子体破裂问题，运维成本低于托卡马克。但仿星器磁场结构极其复杂，建造难度远高于托卡马克，单站造价也更高。南极在 2075 年后开始大规模部署仿星器，与 T 型形成互补。

=== 新型聚变电站（质子聚变实验） ===

- 装置：多种约束方案并行攻关（包括托卡马克变体、仿星器变体、惯性约束等）
- 燃料：纯质子（氕氕）
- 占比：约 7%，均为实验性质或示范电站，大部分尚未并入电网
- 特点：原料直接采用氢气，无需氚等稀缺同位素。但质子聚变对等离子体温度和约束时间的要求远超氘氚聚变，技术远未成熟。当前状态：实验室攻关和少量示范电站，距商业化尚远。

== 氘氚聚变：绝对主流 ==

南极最成熟、最主力的聚变技术仍是氘氚（D-T）聚变。南极能源集团在这一领域拥有极其成熟的技术积累，是全球唯一真正实现氘氚聚变大规模商业化运营的实体。4000+ 座聚变电站中，约 93%（T 型 + S 型）均为氘氚装置，构成了南极电网的绝对基座。

== 能源定价与 J/AY 单位 ==

南极统一使用 J/AY（焦耳/南极元）作为能源价格的标准计量单位，将所有能源形式拉到同一尺度比较。南极元缩写为 AY。

=== 电力（当前 D-T 聚变时代） ===

当前标准电价：800 kWh/AY = 2.88 GJ/AY。这一价格基于大规模氘氚聚变托卡马克的商业化运营，已经极低。

=== 电力（质子聚变突破后，远景） ===

质子聚变技术突破并大规模建成投运后，电价将进一步暴跌至 20000 kWh/AY = 72 GJ/AY。这是远景目标，当前尚未实现。

=== 金属氢 ===

金属氢含能约 216 MJ/kg（0.216 MJ/g）。其价格经历了剧烈变动：
- 早期（2058-2070）：~15 AY/g，昂贵奢侈品，仅极少数军用和特种载具使用。
- 2070 年后：技术突破使价格暴跌至约 0.075 AY/g（原价的 1/200）。
- 按 J/AY 计：1 AY 买到约 13.33g 金属氢，含能 2.88 MJ。

=== 电力 vs 金属氢 ===

同样花 1 AY，买到的电力能量（2.88 GJ）是金属氢能量（2.88 MJ）的 1000 倍。差距源于底层物理：聚变是核能，金属氢是化学复合能，能量密度相差数个数量级。电力碾压是聚变物理的必然，而非市场扭曲。但氢载具在能量密度（重量）和补能速度上对纯电保有优势，二者是**场景互补**而非价格竞争，这构成了南极交通能源"同台竞技"的格局。

== 电网 ==

南极主干网采用特高压直流输电（HVDC），500kV+ 级别。全直流主干网，聚变电站输出经换流站整流为直流，到负荷中心逆变为交流。4000+ 座站走交流同步需全部发电机相位对齐，调度复杂度过高，直流天然规避此问题。硅基智能控制换流站电力电子，直流变换环节的固有损耗被压到极低。

导线以铜为主，偏远或赶工期可用铝。超导线材成本过高，不经济。聚变燃料几乎免费，线损不是核心约束，无需像人类政权那样追逐超高电压等级。

=== 横贯南极山脉应急输电网 ===

8 条特高压直流输电线路跨越横贯南极山脉，连接东西南极洲。设计目标：任一侧电力设施全部毁损，另一侧可经由跨山线路维持对方基本生存用电。纯战略韧性工程，不计经济回报。平时仅 2 条以极低功率运行，定期轮换为另外 2 条，确保 8 条线路均可随时投入满负荷运行。

线路命名：和谐线、共生线、不朽线、曙光线（理念命名）；横贯南极山脉第一线、罗斯冰架线（地理命名）；冰山一线、花岗岩线（风物命名）。

== 交通能源 ==

南极没有加油站，只有加氢站和充电站。加氢站负责加氕氘氚等聚变原料，也负责加金属氢。充电站负责给车充电，价格与全国统一电价相同。

与聚变燃料相比，金属氢的价格波动较大。金属氢曾经在南极是相当贵重的"奢侈品"，1 克金属氢价格高达 15 AY。那些装不下聚变设备的小型交通载具可就非常痛苦了，要么彻底改成电车，要么就要忍受金属氢高昂的成本。不过自 2070 年以后这一情况发生转折，随着技术进步，金属氢价格降至约 0.075 AY/g（跌破原价的 1/200）。从此氢载具在能量密度和补能速度的优势得以释放，在南极交通体系中占有了一席之地。

=== 混合站点 ===

南极民间将充电站与加氢站合体的综合能源终端称为"混合站点"或"综合站点"。混合站点不仅是补能点，更是社区商业节点——站内电价在原本已极低的全国统一电价基础上再降一个数量级，房租同样再跌一个数量级。低廉到近乎免费的能源和场地成本，使混合站点天然吸附了大量配套服务。

基准年份：2072年后。站点电价：8000 kWh/AY（全国电价的 1/10）。

== 钠离子电池 ==

南极共和国是全球唯一彻底废除锂离子电池、死磕钠离子电池的政权。其他主要政权（美联国、亚洲联合体、火星联盟、欧洲联合体等）均沿用锂离子电池技术路线。

轻型车辆（无法安装聚变装置的乘用车、小型机械等）的电驱主力是钠离子电池。南极在这一领域拥有极其成熟的产业和技术积累。

负极结构：石墨导电骨架 + Na₂S 离子导电骨架 + Na⁰ 氧化还原中心 + 二苯乙烯门控。

负极由四种组分协同构成：

- 石墨颗粒：电子导电骨架。每个石墨颗粒表面负载 Na₂S 壳层和门控分子。不参与氧化还原，仅提供电子通路。
- Na₂S（硫化钠）：Na⁺ 离子导电骨架。反萤石结构（S²⁻ 构成面心立方，Na⁺ 占据全部四面体空隙），Na⁺ 在晶格内迁移势垒天然极低。电子绝缘体，必须负载于石墨之上才能参与电子交换。Na₂S 的 S²⁻ 始终保持 -2 价，不参与氧化还原——它只是 Na⁺ 的"高速公路"。
- Na⁰（金属钠）：真正的氧化还原中心。充电时在石墨/Na₂S 复合颗粒的孔隙内沉积成核，被 Na₂S 骨架物理限域；放电时溶解为 Na⁺，经 Na₂S 晶格迁移至电解质。枝晶被 Na₂S 刚性骨架阻挡。
- 二苯乙烯门控（反式-二苯乙烯，C₁₄H₁₂）：锚定于石墨边缘的分子级物理开关。元素组成仅 C、H 两种，不含 N/S。通过 C=C ⇌ C-C 的氧化还原驱动构象坍缩/伸展，物理堵门/开门，彻底消灭静置漏电。

负极结构拓扑：

```
    石墨芯 (电子通路)          Na₂S 壳 (Na⁺ 通路)        电解质
   ══════════════════      ═══════════════════      ╼╼╼╼╼╼╼╼
   │         │                        │
   │  石墨边缘 C ── 门控分子 ──────────→ (伸入电解质)
   │         │                        │
   │         │              Na₂S 表面  │
   │   Na⁰ 沉积位点                    │
   │   (颗粒间孔隙)                    │
   │                                  │
   正极 ←── e⁻ 经石墨网络 ── Na⁰ 沉积/溶解
                    Na⁺ 经 Na₂S 晶格 → 电解质

充电: Na⁺ + e⁻ → Na⁰   (Na⁰ 在孔隙内成核, 石墨供 e⁻, Na₂S 送 Na⁺)
放电: Na⁰ → Na⁺ + e⁻   (Na⁺ 经 Na₂S 出负极, e⁻ 经石墨出负极)
```

门控机制 —— 静息态 vs 放电态：

```
静息态 (充电完毕, Na⁰ 在场, 电位 ~-2.71V):

  ══C──Ph──CH₂CH₂──Ph    Ph
                       ╲ ╱
                        C──C      ← C=C 被还原为 C-C 单键 (sp³)
                       ╱ ╲       绕 C-C σ 轴自由旋转
                      H    H
                        │
                      末端苯环乱甩, 分子塌缩为无规线团
                      → 物理堵死 Na₂S 通道出口
                      → Na⁺ 无法逃逸, 静置漏电为零

  C=C + 2e⁻ ⇌ C-C      门关, 两个电子储存在 C-C σ 键框架中


放电态 (Na⁰ 溶解, 电位上升):

  ══C──Ph──CH₂CH₂──Ph    H
                       ╲ ╱
                        C═C      ← C-C 被氧化回 C=C 双键 (sp²+π)
                       ╱ ╲       恢复反式刚性平面构象
                      Ph   H
                        │
                      末端苯环直挺挺伸入电解质
                      → Na₂S 通道畅通无阻
                      → Na⁺ 通行

  C-C ⇌ C=C + 2e⁻      门开, 电子经石墨网络输往正极
```

各碳原子键数核实:

  石墨内部 C:          3 个面内 C-C σ + 1 个 pz π 离域 = 4 (sp²)
  石墨边缘 C (接 Ph):   2 个面内 C-C σ + 1 个 C-Ph σ + 1 个 pz π = 4 (sp²)
  锚点/桥/末端苯环各 C: 2 个环内 C-C σ + 1 个外接 C-C σ + 1 个 π = 4 (sp²)
  -CH₂CH₂- 间隔臂各 C:  2 H + 2 C σ = 4 (sp³)
  门控 CH=CH 各 C (放电态): 1 H + 1 C σ + 1 C=C (σ+π) = 4 (sp²)
  门控 CH-CH 各 C (静息态): 2 H + 2 C σ = 4 (sp³)

门控总结:

| 条件 | 门控 C-C 键 | 构象 | Na⁺ 通道 | 漏电 |
|------|------------|------|----------|------|
| 静息态 (充电完毕) | C-C 单键, 自由旋转 | 无规线团塌缩 | 物理堵死 | 零 |
| 放电态 (电位上升) | C=C 双键, 反式刚性 | 直线伸展 | 畅通 | — |

正极 vs 负极门控对比:

| | 正极 | 负极 |
|---|---|---|
| 门控分子 | C=O 酮羰基 | C=C 二苯乙烯 |
| 门控元素 | C, H, O | C, H |
| 锚定方式 | C-C 共价 (石墨─Ph) | C-C 共价 (石墨─Ph) |
| 间隔臂 | -CH₂CH₂- (σ) | -CH₂CH₂- (σ) |
| 开关类型 | 化学开关 (诱导效应) | 物理开关 (构象坍缩) |
| 关门机制 | C-O·⁻ 电子推斥削弱冠醚亲和力 | C-C 单键旋转塌缩堵住 Na₂S 出口 |
| 开门机制 | C=O 中性态, 冠醚亲和力恢复 | C=C 刚性平面伸展, Na⁺ 通行 |

电解质：有机离子液体，化学式为 AlR3，其中 R 为有机阴离子，结构如下：

R = (4-氧负离子苯基)(4-羟基苯基)(4-甲基苯基)甲烷负离子

$$\text{R}^- = \ce{C(C6H4-O^-)(C6H4-OH)(C6H4-CH3)}-$$

即三苯甲基骨架上连接三个不同取代基：
- 苯环(1)：para-O- ——酚氧负离子。负电荷源，与 Al3+ 配位。
- 苯环(2)：para-OH——酚羟基。提供适度氢键，维持液体骨架。
- 苯环(3)：para-CH3——甲基。惰性稀释，打散氢键网络，防止纯 OH 体系导致的粘度过高和蒸馏困难。

Al3+ 不参与任何电极反应，仅作为电解质阳离子存在。Na+ 和 R- 均可迁移，载流子为 Na+。

正极结构（从外向内）：
- 石墨层：导电骨架，不参与氧化还原。
- 二茂铁（Fc）：电子储库。通过 C≡C 三键共价锚定于石墨边缘碳，双 π 通道贯穿石墨 pz ↔ C≡C ↔ Cp π ↔ Fe，电子交换畅通。三键键能 ~839 kJ/mol，远高于 π-π 吸附，Fc 在电解液中不会脱附。
- 酮羰基（C=O）：电化学开关。通过共价键锚定于石墨表面，直接从石墨获取电子。被还原后生成自由基阴离子 C-O·-，通过诱导效应增强冠醚对 Na+ 的亲和力。
- 饱和碳间隔臂（-CH2CH2-，[σ]）：连接羰基与冠醚。σ 键隔断 π 共轭，阻止单电子从羰基漂移到冠醚，仅传递诱导效应。
- 15-冠-5（Crown）：选择性囚禁 Na+，空腔直径 ~2 Å，对 Na+ 具有高度特异性。通过 -CH₂-O-Ph- 锚定于石墨——CH₂ 为 sp³，无 p 轨道，石墨 π 共轭在此断裂，冠醚电学上与石墨隔离。
- 石墨 → 冠醚：共价键锚定，sp³ 打断 π，电气隔离（仅物理锚定 + 接收诱导效应信号）
- 石墨 → 二茂铁：C≡C 三键共价锚定，双 π 通道（电子储库，快速交换）
- 石墨 → 羰基：共价键，电子开关
- 羰基 → σ间隔臂 → 冠醚：只传诱导效应，不传单电子（σ 键绝缘）

正极有两个并行反应，均直接与石墨发生电子交换：

放电反应：
负极：Na(s) → Na+ + e-

正极反应一（电子储库）：
Fc+ + e- → Fc

正极反应二（开关）：
C=O + e- → C-O·-
C-O·- ──诱导效应(σ)──→ 冠醚氧原子 ──→ 冠醚囚禁 Na+

充电反应：
正极反应一：Fc → Fc+ + e-
正极反应二：C-O·- → C=O + e-，冠醚释出 Na+
负极：Na+ + e- → Na(s)

总反应：
Na(s) + Fc+ + C=O ⇌ Fc + C-O·-[Crown⊃Na+]

固有缺陷：

钠离子电池存在两类不可根除的化学缺陷，二者并行作用，将电池寿命约束在 ~10 年。

== 缺陷一：冠醚磨损（门锁磨钝）==

羰基被还原生成自由基阴离子后，虽然 σ 间隔臂阻止了单电子的直接传输，但负电荷通过诱导效应仍然对冠醚氧原子产生微弱的电子推斥。经过反复充放电循环，冠醚的 Na+ 结合位点会缓慢退化——不是电池"老了"，而是门锁在每次开合中被自身的开关机制微量磨损。这一缺陷无法通过工程手段根除。

== 缺陷二：C-O·⁻ 自由基副反应（定点报废）==

酮羰基被还原生成的 C-O·⁻ 自由基阴离子虽然绝大部分电子通过石墨网络完成有用功，但极少量会与周边有机物发生不可逆副反应。这些副反应遵循共同的原则：每个事件消耗一个 C-O·⁻，产物均为闭壳层，不产生新自由基，无一链式反应。四条路径累积叠加，构成制约钠电池寿命的"头号元凶"。

---- 副反应一：α-H 抽取 → 石墨电子汇淬灭 ----

C-O·⁻ 抽取相邻 σ 间隔臂 -CH₂- 的 α-H 原子：

$$
\ce{
    C-O^{.-} + H-CH2-CH2-O-... -> C-OH + ^{\bullet}CH-CH2-O-...
}
$$

速率决定因素：C-O·⁻ 的氧与间隔臂 α-H 须处于 ~180° 的 O···H-C 有利取向才能发生抽取，分子热运动大部分时间不对准，反应概率极低。

生成的碳自由基 ·CH- 距石墨表面仅 ~3 Å，单电子瞬间隧穿注入石墨 pz 电子汇，自由基被淬灭：

$$
\ce{
    ^{\bullet}CH-CH2-O-... + e-_{(graphite)} -> ^{-}CH-CH2-O-... ->[H^+] CH2-CH2-O-...
}
$$

结果：**死了一个 C=O 开关，间隔臂恢复原状。不传播。一换一。**

---- 副反应二：痕量水还原 → 闭壳层终止 ----

C-O·⁻ 遇电极表面吸附的痕量 H₂O（ppb 级）：

$$
\ce{
    C-O^{.-} + H2O -> C-OH + OH^{-}
}
$$

OH⁻ 为闭壳层阴离子，无单电子，不可传播。随即被电解质中的 Al³⁺ 捕获（强 Lewis 酸）：

$$
\ce{
    OH^{-} + AlR3 -> [Al(OH)R2] + R^{-}
}
$$

R⁻ 为酚氧负离子，闭壳层，不再反应。结果：**一个 H₂O 灭一个开关。H₂O 总量 ppb 级，耗尽即停。一换一。**

---- 副反应三：相邻 C-O·⁻ 直接耦合 → 过氧桥 ----

石墨表面负载密度高时，两个相邻 C-O·⁻ 的氧原子间距 < 3 Å，直接偶联：

$$
\ce{
    (A) C-O^{.-} + ^{\bullet}O-C (B) -> (A) C-O-O-C (B)
}
$$

产物过氧桥两个氧均为闭壳层（各 8 电子），无单电子残留。结果：**两个相邻开关配对报废。一换二。** 概率极低——要求两个 C-O·⁻ 同时存在且氧间距恰好够近。

---- 副反应四：残存酚羟基 H 抽取 → 苯氧自由基被石墨淬灭 ----

C-O·⁻ 抽取电极表面残留酚羟基的酚羟 H：

$$
\ce{
    C-O^{.-} + HO-Ph-... -> C-OH + ^{\bullet}O-Ph-...
}
$$

酚氧自由基 ·O-Ph- 的苯环与石墨 C-C 共价连接，π 共轭通畅——单电子瞬间被石墨 pz 汇吸收淬灭：

$$
\ce{
    ^{\bullet}O-Ph-... + e-_{(graphite)} -> ^{-}O-Ph-... ->[H^+] HO-Ph-...
}
$$

结果：**死了一个 C=O 开关，酚羟基恢复原状。不传播。一换一。** 取决于石墨表面制备工艺——锚定步骤残留的未成键酚羟基即是"挂在身边的定时炸弹"。

---- 四条副反应总结 ----

| 副反应 | 引发条件 | 传播 | 终止方式 | 每事件死几个开关 | 速率约束 |
|--------|---------|------|---------|-----------------|---------|
| 一 | C-O·⁻ + α-H 180° 取向 | 无 | ·CH- 被石墨 e⁻ 淬灭 | 1 | 取向概率极低 |
| 二 | C-O·⁻ + 痕量 H₂O | 无 | OH⁻ 闭壳层, Al³⁺ 捕获 | 1 | H₂O ppb 级耗尽 |
| 三 | 两相邻 C-O·⁻ 氧距 <3 Å | 无 | 过氧桥闭壳层 | 2 | 概率极低 |
| 四 | C-O·⁻ + 残留酚 OH | 无 | ·O-Ph 被石墨 e⁻ 淬灭 | 1 | 残留 OH 数量有限 |

全部自终止，无一链式反应。10 年寿命是这四条路的累积概率叠加——每条路都极慢，但四条路一起跑，十年跑完。

---- 技术反思：根植于化学硬约束 ----

上述两条缺陷——冠醚磨损与 C-O·⁻ 自由基副反应——均扎根于正极材料的化学本质，无法通过任何工程手段根除。σ 间隔臂的 α-H 无法替代（全氟化 -CF₂CF₂- 虽无 C-H，但氟的强吸电子诱导效应会干扰 C=O 开关对冠醚的调控灵敏度）；痕量水无法在产业化条件下绝对消除（ppb 级已是人类制造工艺的极限）；C-O·⁻ 的自由基活性无法压制（它是正极反应二的必要中间体，消除了它电池就不工作）。

硅基智能对此亦无解——钠离子电池的极限寿命就是 15 年。南极共和国、火星联盟、亚洲联合体、美联国在这一点上完全相同。这是化学宿命，无关政权，无关技术差距。
