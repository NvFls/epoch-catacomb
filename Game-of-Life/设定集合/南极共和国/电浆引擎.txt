# 电浆引擎

信天翁-I 水平推进系统。碟体后部嵌入式，纯电力驱动，在大气层内实现等离子体推进。

== 基本原理 ==

1. 进气：前方空气经进气口吸入引擎腔体
2. 电离：高能电子束轰击空气分子，产生阴阳粒子（N₂⁺、O₂⁺ + 自由电子），气体本体保持低温
3. 加速：电磁场将等离子体高速向后喷出（具体方案待定）
4. 排气：等离子体喷流经喷口排出，产生水平推力

== 动力参数 ==

- 输入电功率：29 MW（双仿星器供电）
- 电→推转换效率：~65%
- 推力功率：~18.9 MW
- 信天翁-I 极速：~0.2 马赫（68 m/s, ~260 km/h）

== 电离段 ==

高能电子束电离。聚变堆提供高电压，电子束粒子直接撞击空气分子外层电子实现电离，不依赖气体本体温度。避开了热电离（温度→壁面熔化）和微波大功率电离（壁面热负荷）的两条死路。

- 电离方式：外部注入高能电子束
- 优势：气体本体保持相对低温，壁面热负荷可控
- 电压不是瓶颈（聚变堆供电）
