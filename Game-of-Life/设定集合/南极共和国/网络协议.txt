南极共和国网络协议体系

== 总体架构 ==

根据南极共和国全国信息技术委员会（NARITC，National Information Technology Committee of the Antarctic Republic）规定，南极网络仅划分4层（抛弃了OSI七层模型中的数据链路层、会话层、表示层）：

    物理层 → 网络层 → 传输层 → 应用层

网络层直接建立在物理层之上。加密和会话管理被视为应用层的一部分，不再有独立的"会话层"和"表示层"。

主流通信介质仍然是光纤，量子通信成本极高且不稳定，仅在超前沿机构测试。


== 物理层 ==

南极主流通信介质：光纤。无线电也有广泛应用，但存在一个统一抽象层：

AllRadioWave 无线电波协议：
在该协议下，无线电波通信介质只是不同种类的无线电波，不再有 Wifi、5G、4G 的区分。AllRadioWave 并非强制所有无线电使用统一协议，而是在所有无线电协议之上加了一层抽象层方便开发和使用。根据 NARITC 强制要求，南极所有无线电设备必须支持该协议。


== 网络层 ==

南极有两个网络层协议：ZP（主流）和 SP（淘汰边缘）。

### ZP（ZeroProtocol / 零号协议）

ZP 是南极几乎唯一的网络层协议。由后期进化的硅基智能完全从零开发，与 IPv4/IPv6 完全不兼容。

核心特征：

1. 标识符绝对充足：每个节点有 2048 个标识符（IPv4 仅 32 个），完全不担心不够用。

2. 不做兼容性妥协：不允许 IPv4 或 IPv6 节点接入。

3. 绝对扁平化：完全摧毁内网概念，杜绝一切 NAT/网关。

4. 介质无关性：可同时用于电子光纤通信和量子通信。不论何种通信介质（铜线、光纤、无线电波），统一抽象为路由路径。管理具体通信介质是物理层的职责。

5. 拓扑图替代路由表：ZP 协议中没有路由表，只有网络拓扑图。没有任何一个节点能记住整个网络的拓扑图——即使南极国家专门维护的超级路由器也只能记住千万级节点的拓扑图，普通家用设备只能记住几百个节点。

6. 强制路由义务（ZP 协议精髓）：所有接入网络的设备都有义务成为路由节点，必须承担数据包转发义务。不允许集线器、交换机这种"半吊子"接入，所有接入设备必须为路由器，必须具备路由功能。

7. 权力下放（ZP 协议最大胆的设计）：允许节点自己设计算法选择数据包发送路径。每个节点在自己的拓扑图范围内，ZP 网络只提供：自己记住的拓扑图、图中每个节点的信誉值、其他节点眼里拓扑图路径的权重。节点可以自己设置拓扑图中的权重，可以自己设计"把数据包发给谁"的算法。ZP 网络不提供统一的选路算法，这需要每个节点自己实现。节点记住的拓扑结构大小与其指定路由权重和路径的权力成正比，出现冲突时，采用记住路由权重更多的节点的指示。

    第7条与第6条不冲突——不论节点选择何种算法，都必须履行路由义务。

ZP 包格式：
|目标节点地址（2048 比特，256 字节）| 发送节点地址（2048 比特，256 字节）| ZP 协议保留字段，256 字节 | 数据段，大小可自定义为 2^n 字节，0<=n<=11|

南极大部分设备为兼容性考虑同时支持 ZP 和 SP，但只有 ZP 最受欢迎。巴斯德（海鸥记者）正是通过 ZP 协议把文章发回南极日报。

### SP（Super Protocol / 超网协议）

SP 是早期硅基智能在 IPv6 基础上改进而来，最初目标是力图把 IP 资源变得和空气一样唾手可得。

这个协议对南极来说非常古老，Bug 极多，庞大臃肿，处于淘汰边缘。SP 做了太多兼容性让步，甚至允许 IPv4 节点接入，被南极人民（包括基准人类和其他物种）戏称为"老爷协议"、"傻子协议"。截止 2070 年，SP 在南极已处于淘汰边缘。


== 传输层 ==

官方有两个传输层协议，但民间开发者花样百出。

### ETE（End to End）
严格的链路可靠性和完整性验证，发送端-接收端缓冲区设计，非常严格的验证和重传机制。延迟和性能占用偏高，主张"宁可慢，不可坏"。主要用于南极科研机构通信、硅基智能的自动工厂和分布式经济调节网络。南极民间不太喜欢。

### ST（Speed Transport）
仅具备简单的链路可靠性验证和重传，简单且性能占用低。在南极民间非常受欢迎，几乎是民间开发应用的首选。

### 民间的"群魔乱舞"
南极并非所有开发者都买 NARITC 的账。约 1/3 的民间开发者高呼"干掉传输层！这里属于应用层！"，要么使用自己圈子写的传输层协议，要么把类似功能在应用层实现，直接不用传输层，把应用直接建立在网络层之上。


== 应用层 ==

应用层是南极广大开发者最喜欢的地方，协议非常多非常乱，以下是几个主要的：

### Email 协议
专注于电子邮件服务。

### zWeb 协议
被南极网民赞誉为"新时代 HTTPS"。加密过程与 HTTPS 正好相反：使用对称加密算法加密非对称加密算法的密钥，再用那个非对称加密密钥传输数据。拥有非常严格的加密和链路可靠性验证，主要用于上网冲浪。

浏览器地址栏格式：zweb:webname（webname 仅允许英文字符、"-" 和 "_"）。

### ZPFS
类似于 IPFS，用于全民公共数据存储。IPFS 全称是 Inter Planetary File System，其中的"IP"并非指 IP 协议。但因为在南极 ZP 协议太出名，加上大家都以为"IP"指 IP 协议（南极早就淘汰了），所以广大南极网民坚持把 IPFS 叫做 ZPFS。

ZPFS 只负责存储、分发、寻找数据，不负责加密。对外暴露接口，允许其他应用接入整个 ZPFS 网络。加密任务交给开发者自行实现。


== 治理机构 ==

南极共和国全国信息技术委员会（NARITC）负责网络协议标准的制定和维护。
