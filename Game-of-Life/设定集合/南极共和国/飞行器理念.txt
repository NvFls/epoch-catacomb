南极共和国飞行器理念

== 信天翁-I ==

南极有史以来最成功、技术最成熟的大型空中飞行器。一款纯硅基智能操控、无碳基乘员的碟形反重力多用途平台。

== 基本参数 ==

- 外形：碟形，半径50m，平均厚度5m（碟形圆柱近似）
- 总体积：~39,270 m³（π × 50² × 5）
- 造价：450万 AY/台
- 采购量：10,000+（2068年军队集装箱化/模块化改革后采购量飙升）

== 动力与能源 ==

- 主能源：2 台 D-T 仿星器聚变反应堆并联（直径 ~12m/台，含等离子体体积 ~79 m³/台，D-T 燃料罐 ~36 m³/台置于仿星器中心空腔），总热功率 ~110 MW_th
- 发电：2 套超临界 CO₂ 布雷顿循环发电机组，总电输出 ~40 MWe。气冷散热——内置风道 + 换热器，外部空气经进气口掠过换热器带走废热，热空气排出。适应南极极寒至 40°C 高温环境（高温下压缩前密度略降，循环净效率小幅下滑，但不停摆）
- 垂直升力：3 套反重力装置，等边三角排列（间隔 120°），每套 = 力场发生器 + 畸变器。反重力场永远与重力反向，不提供水平推力。差动调节三套装置的 λ 和 γ 实现俯仰、滚转、偏航
- 水平推进：电浆引擎（碟体后部嵌入式，电子束电离空气 + 电磁加速喷出等离子体，详见电浆引擎.txt）

== 控制与计算 ==

- 2 台 HUP-1001 量子计算机，每台 1024 量子比特
- 两台互为备份，一台运行，一台休眠
- 2 个硅基智能驻留操控，无需碳基乘员

== 传感器 ==

- 4 块相控阵雷达，360° 覆盖

== 畸变器参数 ==

- λ = 3.5（大小畸变器放大系数）
- k = 0.2（畸变器能耗系数，军用高水平）
- 悬浮：E = g/(1+λ) = g/4.5 ≈ 0.22g
- 满功率向上加速：a_net_max = −λ·g = −3.5g
- 功耗：P(λ) = P₀·e^(k(λ−1))，λ=3.5 时 P/P₀ = e^0.5 ≈ 1.65
- γ：各向畸变器使场贴合碟形——碟面水平方向 γ 小（衰减慢，伸得远），垂直方向 γ 大（衰减快，收得紧）。方向间平滑过渡，邻差小，S 温和，功耗不炸

== 飞行性能 ==

- 极限速度：~0.2 马赫（~260 km/h）。碟形非气动外形，反重力不提供水平推力，空气阻力为限制主因
- 超音速：南极科学界认为突破音障几无可能——钝面碟形跨音速激波阻力极大，且与动力无关，是物理外形锁死了速度上限

== 空间分配 ==

总体积 ~39,270 m³。

每台仿星器按直径 12m 环形装置计算（大半径 R≈4m，含磁体线圈+真空室+屏蔽+包层的小半径 a≈2m，总厚 ≤5m）：

环形体积 = 2π² × R × a² ≈ 2×9.87×4×4 ≈ 316 m³/台。

每台中心空腔（R−a≈2m，高~4m）内安置 D-T 燃料储罐（~36 m³），为独立部件。

双仿星器并联布置，sCO₂ 发电机组相应增加至 2 套。

| 系统 | 占比 | 体积 | 备注 |
|------|------|------|------|
| D-T 仿星器 ×2 | 3.0% | ~1,180 m³ | 2台，各含本体~316 m³ + 附属结构 |
| D-T 燃料储罐 ×2 | 0.2% | ~72 m³ | 每台仿星器中心空腔各 1 个 |
| sCO₂ 发电机组 ×2 | 10% | ~3,930 m³ | 2 套，涡轮+压缩机+发电机 |
| 3 套反重力装置 | 10% | ~3,930 m³ | 等边三角分布于碟缘 |
| 电浆引擎 | 15% | ~5,890 m³ | 碟体后部嵌入式，电子束电离+电磁加速 |

| 冷却风道+换热器 | 12% | ~4,710 m³ | 内置风道+分布式换热器（双堆热负荷增加） |

模块化载荷舱 ~9,818 m³——轰-6K 机身容积~250 m³ 的约 39 倍。可配置为运输、救援、轰炸、侦察/指挥、额外燃料、完全空舱货运等模式。

碟面上下设大量武器与模块挂载点。自身几乎没有作战功能——只是一个会飞的平台，战斗力来自外挂武器和任务模块。

== 电力分配 ==

双仿星器总发电 ~40 MWe，扣 5% 调度/传输损耗后可用 38 MW：

| 系统 | 功率 | 备注 |
|------|------|------|
| 反重力（3套） | 6 MW | 30% 可用电力，λ=3.5 满功率 |
| 雷达（4面） | 2 MW | 0.5 MW/面，GaN AESA |
| 冷却系统 | 0.5 MW | 抽气风扇+半导体散热片+排气 |
| 电浆引擎 | **29 MW** | 碟体后部嵌入式 |
| 功率盈余 | 0.5 MW | — |
| 总计 | 38 MW | — |

电浆引擎推力功率 ~18.9 MW（29 MW 电 × 65% 电→推效率），推得 ~0.2 马赫。

== 部署能力 ==

- 可爬升至 15km 高空释放小型飞行器（如新生命归乡号滑翔机）
