# CLAUDE.md

本项目为中文科幻小说 **《生命游戏》** 的创作仓库。作者与 AI（DeepSeek）协作进行世界观构建和故事创作，属于探索性的世界构建和叙事实验，并不追求完成一部完整的长篇小说。

## 项目结构

```
情节/                   # 故事情节（按故事线组织）
├── 巴斯德上海报道/      # 巴斯德（海鸥记者）的上海报道
├── 人类叛乱/            # 帕斯卡反抗南极共和国
├── 火星危机/            # 火星外交危机
└── 寓言与插曲/          # 独立寓言与角色档案
设定集合/                # 世界设定文档
├── 核心设定/            # 核心设定（治国理念、声明）
├── 技术设定/            # 技术设定（网络协议、操作系统、能源）
├── 社会与政治/          # 社会与政治
├── 势力设定/            # 势力设定（南极共和国、美联国、亚洲联合体）
└── 名词解释/            # 名词解释
```
