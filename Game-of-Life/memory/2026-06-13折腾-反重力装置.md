> 摘要：反重力装置物理框架——逆转模型/场分布/形状效率η与空间效率V_η/畸变器λγ、10个废稿记录、关键认知：场永远是凸包，碟形天然最优

## 已确定（详见设定文件 反重力技术.txt）

- 逆转模型、净力 F_net = m(g − 2E)、三个状态
- 场分布 E(r) = E₀（内部）/ E₀(r₀/r)²（外部平方衰减）
- 形状效率 η 和空间效率 V_η（两个独立度量）
- 大小畸变器 λ 及功耗 P = P₀·e^(γ(λ−1))
- 形状畸变器：幂律族 E₀(r₀/r)^γ、线性衰减截断、各向畸变器 γ(θ,φ)

## 废稿 —— 以下全部已放弃，记录供后查，不要复用

### 【废稿】凭空抵消模型
最初考虑"装置凭空产生力场抵消重力"→ F_net = m(g−E)，悬浮需 E=g。
**为何放弃：** 与逆转模型的物理本质不同。逆转从 g 借力，悬浮仅需 E=g/2，效率更高且不凭空生力场。仅保留为文件中的对比参考。

### 【废稿】向上为正方向
尝试取向上为正 → F_net = m(2E−g)。
**为何放弃：** 不如向下为正 F_net = m(g−2E) 直观好念。换回向下为正。

### 【废稿】效率 = 被包裹体积/力场总体积
自然平方衰减下 V_E → ∞ → 效率恒为零。
**为何放弃：** 分母无穷大，度量无意义。后来引入 V_η = V_f/V_E 仅在力场有界时有效，但必须强调 η 和 V_η 是两个独立度量。

### 【废稿】η = V_f/V_E（两个效率度量为同一个东西）
尝试证明 Σ(m_i·E(r_i))/(E₀·Σm_i) = V_f/V_E。
**为何放弃：** 严格证明二者不相等。体积比是对空间占用的度量，η 是对质量径向位置的度量，同一体积比下 η 可随质量分布取任意值。

### 【废稿】场强公式 E(r) = K/r²（点电荷类模型）
从 r=0 开始平方衰减 → r→0 奇点爆炸。讨论点电荷内部场（E = γQr/R³）后意识到发生器有物理尺寸。
**为何放弃：** 最终采用 E₀(r₀/r)² 方案——r₀ 为发生器半径，内部常值 E₀ 饱和，奇点被实体结构截住。

### 【废稿】方差作为形状畸变器代价
Var(r) = (1/n)·Σ(r_i−r_avg)²。
**为何放弃：** 方差只看 r 值集合不管排列。平滑椭球和揉烂等体积纸团方差相同，大自然不应给二者抽一样的税。方差瞎了——看不见邻方向 r 是平滑过渡还是乱跳。

### 【废稿】等强度面作为畸变分析对象
取定 E 值，各方向场降到该值时的距离构成等强度面。
**为何放弃：** 不同 E 值下等强度面形状不相似（r ∝ E^(−1/γ)，各向 γ 不同则缩放比不同，越远越歪），无法统一讨论"场的形状"。

### 【废稿】曲率
考虑用高斯曲率衡量等场面扭曲度。
**为何放弃：** AI 助手太笨解释不明白曲率，且 γ(θ,φ) 光滑时等场面自动为正曲率凸包，不反映 γ 的邻方向跳变。

### 【废稿】S = (1/n)·Σ γ'(θ_i, φ_i)²（定义不完整版）
最初将 S 写成单个方向点上的 γ'² 求和：S = (1/n)·Σ_i γ'(θ_i, φ_i)²。
**为何放弃：** 三个问题未交代——(1) γ' 是原始差值还是斜率？(2) "相邻方向"如何界定、采样点如何分布？(3) n 增大时行为不确定。后修正为相邻对斜率均方值的形式（见反重力技术.txt）。


形状畸变器代价 = 邻方向 γ 差平方和：把球面上所有相邻方向的 γ 值配成对，(γ_i−γ_j)² 全加起来。γ 平滑渐变 → 邻差小；γ 乱跳 → 邻差大 → 代价指数爆炸。大自然只看邻方向 γ 跳不跳。线性截断的代价未讨论。

## 讨论中产生的关键认知

- 场永远是凸包——无论各向畸变器怎么扭 γ，场不能产凹角、钩状、分叉。碟形飞行器天然最优，歼-20 的复杂气动外形在反重力场里永远效率低下。
- 技术约束本身即是叙事引擎——第 3 章巴斯德看见歼-20 的震撼，根源不在"人类好厉害"，而在"这玩意按照反重力物理定律不该存在"。
