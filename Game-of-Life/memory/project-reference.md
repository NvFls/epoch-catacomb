## 文件命名规范

- 所有文件使用 `.txt` 扩展名，UTF-8 编码
- 章节文件按模式：`年份/描述.txt` 或 `年份/角色名-事件.txt`
- 设定文件按类别文件夹组织

## 仓库操作

- 所有内容为简体中文
- 文件为纯文本（`.txt`），直接编辑
- 无构建系统、测试、lint——纯创作项目
- Git 用于文本文件的版本控制
- 编辑时保留现有缩进风格（空格，非制表符），保持与周围文本一致的叙事语调
- 故事章节和设定文档应与世界设定保持一致
