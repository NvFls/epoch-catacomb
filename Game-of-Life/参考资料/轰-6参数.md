# 轰-6K 轰炸机参数

来源：公开资料整理（维基百科、快懂百科等）

## 尺寸

| 参数 | 数值 |
|------|------|
| 机身长度 | 34.8 m |
| 翼展 | ~33-34 m |
| 机高 | ~10 m（轰-6K 约 10.36 m） |
| 机翼面积 | ~164-167 m² |

## 重量

| 参数 | 数值 |
|------|------|
| 空重 | ~37.2 吨 |
| 正常起飞重量 | 72 吨 |
| 最大起飞重量 | 75.8-79 吨 |

## 载弹量

| 参数 | 数值 |
|------|------|
| 正常载弹量 | 3 吨 |
| 最大载弹量 | 9 吨（轰-6K 提升至 12 吨） |
| 内置弹舱 | 机身中部 1 个 |
| 外挂点 | 机翼下 2-6 个 |

## 动力与性能

| 参数 | 数值 |
|------|------|
| 发动机 | 2 台 D-30KP-2 涡扇（轰-6K） |
| 最大速度 | ~1,014-1,050 km/h（高亚音速） |
| 巡航速度 | ~786 km/h |
| 最大航程 | ~5,760-7,200 km |
| 作战半径 | ~1,800-2,500 km |
| 实用升限 | 12,800-13,100 m |
| 乘员 | 3 人 |

## 机身容积粗略估算

机身近似直径~3m、长~35m 的圆柱体，总体积约 250 m³。内置弹舱占机身中部一段，有效载荷空间不超过几十 m³。

## 与信天翁-I 对比

| 对比项 | 轰-6K | 信天翁-I |
|--------|-------|----------|
| 长度/直径 | 34.8 m | 100 m |
| 总体积 | ~250 m³ | ~39,270 m³ |
| 载荷舱容积 | 几十 m³ | ~11,780 m³ |
| 载荷倍数 | 1× | ~47 倍于轰-6K 机身总容积 |
